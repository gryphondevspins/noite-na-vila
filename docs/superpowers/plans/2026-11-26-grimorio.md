# Grimório: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkboxes.

**Goal:** Restyle the whole game as a dark tarot grimoire, with a desktop "ritual table", fluid
animation and synthesized sound, without leaking any secret role.

**Architecture:** Art and sound live in `packages/assets` (SVG composed in TypeScript, WebAudio
synthesis). `apps/web` gets reusable presentation components; game rules in `packages/engine` do not
change. One DOM per screen, with mobile and desktop layouts chosen by CSS.

**Tech Stack:** React 19, Vite 8, CSS animations, WebAudio, `@fontsource/pirata-one`,
`@fontsource/eb-garamond`, Vitest, Testing Library, playwright-cli.

**Spec:** [2026-11-26-grimorio-design.md](../specs/2026-11-26-grimorio-design.md)

## Global Constraints

- No rule changes: `packages/engine` is untouched.
- Desktop layout from `min-width: 900px` and `min-height: 560px`.
- Secrecy rules 1–5 of the spec apply to every task.
- No new animation library. Works offline (fonts precached).
- No git repository: no commit steps. Backup of the previous UI is in the session scratchpad.

## Review Focus

1. 16 players at 1366x650 and at 360x640: no seat overlaps another or the card (Task 5, browser).
2. Detective picks two, others pick one: sound cues per secret turn are identical (Task 3).
3. WebAudio missing or blocked: the game plays normally (Task 2).
4. Muted, then reload: stays muted (Task 2).
5. Reduced motion: every card and button is still visible (Task 5, browser).

### Task 1: Tarot art

**Files:** Create `packages/assets/src/tarot.ts`; modify `packages/assets/src/index.ts`,
`index.test.ts`, `svg/logo.svg`, `svg/village.svg`; delete the five old portraits and
`svg/card-back.svg`.

**Interfaces:** Produces `ROLE_ART: Record<RoleId, string>` (SVG data URL, 200x344, no text),
`CARD_BACK: string`, `TAROT_NUMERAL: Record<RoleId, string>`, `LOGO`, `VILLAGE`.

- [ ] Test: each role has its own `data:image/svg+xml` art that parses as XML, has

### Task 2: Sound

**Files:** Create `packages/assets/src/sound.ts`, `sound.test.ts`.

**Interfaces:** Produces `type Cue = 'flip' | 'bell' | 'finale'` and
`sound: { play(cue: Cue): void; unlock(): void; isMuted(): boolean; setMuted(m: boolean): void }`.
Mute key: `noite-na-vila:som`.

- [ ] Tests: without `AudioContext`, `unlock` and every `play` do not throw; a constructor that
  throws does not throw out; `setMuted(true)` is read back by a freshly created instance

- [ ] Fail, implement (noise wind with slow LFO, random crackles, bell from inharmonic partials),
